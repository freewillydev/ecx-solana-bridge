# Implementation status — 2026-10-01

**This is an unfinished development checkpoint, not a deployable custody release.** Both real ledger-driven directions and full refunds have completed. The ordinary paused worker reconciles recorded payments, restores native input locks and journals source eligibility loss and settled native finality changes. Proven native source conflicts now have reversible deficit accounting, covered by offline contracts. `implementationReady = False` in `Bridge.Worker`; it is deliberately not a configuration toggle. New orders and unsigned deposit transactions cannot be requested through the customer API. No administrator resume endpoint is exposed.
